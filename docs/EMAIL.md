# מיילים: אימות מייל ושחזור סיסמה

הקוד כבר מוכן. עד שמגדירים שליחת מיילים, האתר עובד כרגיל אבל **בלי** אימות מייל ובלי "שכחתי סיסמה" (הכפתור פשוט לא מופיע).

## מה קורה כשמיילים מוגדרים
- **הרשמה:** נשלח מייל אימות (קישור תקף 3 ימים). **משתמשים קיימים** מקבלים מייל כזה אוטומטית בכניסה הראשונה אחרי שהמיילים הופעלו. אפשר להשתמש באתר מיד, אבל **הוספת חברים ושליחת גלויות דורשות מייל מאומת**.
- **שכחתי סיסמה:** נשלח קישור לאיפוס, תקף שעה, חד-פעמי. אחרי האיפוס כל ההתחברויות הישנות מתבטלות, והמשתמש נכנס אוטומטית. המערכת עונה אותו דבר בין אם המייל קיים ובין אם לא (כדי שאי אפשר יהיה לבדוק מי רשום).
- **שינוי סיסמה** מתוך ההגדרות (למי שמחובר).
- הקישורים נראים כך: `https://הכתובת-שלך/#/reset/...` ו-`#/verify/...`. החלק שאחרי ה-`#` אף פעם לא נשלח לשרת ולא נרשם ביומנים.

## אפשרות א': Gmail (בלי דומיין משלכם)
מתאימה להתחלה ולקבוצה קטנה. **לא נבדקה מול Gmail אמיתי** (הבדיקות האוטומטיות רצות מול שרת SMTP מדומה), אז השליחה הראשונה היא הבדיקה האמיתית.
- **מגבלות:** עד 500 נמענים ביום בחשבון Gmail רגיל (בזמן הכתיבה). המייל יוצג ללקוחות כשולח מכתובת ה-Gmail. מיילים עלולים להגיע לפעמים לספאם.
- **מומלץ לפתוח כתובת Gmail ייעודית לאתר** (ולא להשתמש בכתובת האישית). סיסמת אפליקציה נותנת גישה לתיבה, ובחשבון ייעודי אין שם כלום חוץ ממיילי המערכת.

1. בחשבון ה-Gmail: myaccount.google.com ← אבטחה ← **אימות דו-שלבי** (חייב להיות מופעל).
2. myaccount.google.com/apppasswords ← שם כלשהו (למשל `daily-planner`) ← Create ← מעתיקים את הסיסמה (16 תווים, **בלי רווחים**).
3. בטרמינל (מחליפים את הערכים; חשוב: `@` בתוך הכתובת ב-SMTP_URL נכתב `%40`):
   ```bash
   fly secrets set -a dailyplanner \
     SMTP_URL='smtps://YOURNAME%40gmail.com:APPPASSWORD@smtp.gmail.com:465' \
     MAIL_FROM='היום שלי <YOURNAME@gmail.com>' \
     BASE_URL='https://dailyplanner.fly.dev' \
     OPERATOR_NAME='השם שלכם' \
     CONTACT_EMAIL='כתובת-לפניות@example.com' \
     MAIL_PROVIDER_NAME='Google (Gmail)'
   ```
4. בודקים: `https://dailyplanner.fly.dev/api/health` ← צריך להופיע `"mail":true`. ואז נרשמים בחשבון בדיקה ובודקים אימות ו"שכחתי סיסמה".
5. **חשוב:** אחרי ההפעלה, כל החשבונות הקיימים נחשבים "לא מאומתים". **בכניסה הראשונה של כל משתמש קיים הוא מקבל אוטומטית מייל אימות** (לכל היותר פעם ביום, ורק אם אין קישור תקף ממתין), ובאתר מוצג באנר עם "שליחה מחדש". עד האימות הוא לא יכול להוסיף חברים או לשלוח גלויות.
6. אם משהו נכשל: `fly logs -a dailyplanner`. שגיאת `535` = סיסמת אפליקציה שגויה או שהאימות הדו-שלבי כבוי. לבטל סיסמת אפליקציה: אותו עמוד ב-Google.

## אפשרות ב': דומיין משלכם + Resend (מסלול חינמי, ושליחה מכתובת משלכם)
בזמן הכתיבה: עד 3,000 מיילים בחודש ו-100 ביום, ודומיין מאומת אחד. **המחירים והמגבלות משתנים, בדקו ב-resend.com/pricing.**
**כדי לשלוח לכתובות של אנשים אחרים חובה דומיין משלכם עם רשומות DNS.**

1. **דומיין.** צריך דומיין שבבעלותכם ושאפשר לערוך בו רשומות DNS. מומלץ תת-דומיין ייעודי לדואר, למשל `mail.example.com`.
2. **חשבון.** נרשמים ב-resend.com.
3. **הוספת הדומיין.** Domains ← Add Domain ← מזינים את הדומיין. Resend מציגה רשומות DNS (SPF, DKIM ועוד). מעתיקים אותן אחת לאחת לספק ה-DNS שלכם. אחרי כמה דקות עד שעות, לוחצים Verify. עד שהדומיין מאומת, שליחה לאחרים תיכשל.
4. **מפתח API.** API Keys ← Create API Key ← הרשאת Sending access ← מעתיקים (מתחיל ב-`re_`, מוצג פעם אחת).
5. **הגדרה ב-Fly.** מהטרמינל (מחליפים את הערכים שלכם):
   ```bash
   fly secrets set -a dailyplanner \
     SMTP_URL='smtps://resend:re_המפתח_שלכם@smtp.resend.com:465' \
     MAIL_FROM='היום שלי <noreply@mail.example.com>' \
     BASE_URL='https://dailyplanner.fly.dev' \
     OPERATOR_NAME='השם שלכם' \
     CONTACT_EMAIL='כתובת-לפניות@example.com' \
     MAIL_PROVIDER_NAME='Resend'
   ```
   זה מפעיל מחדש את המכונה. הנתונים בטוחים (נוצר גיבוי `boot-*` אוטומטית).
6. **בדיקה.** נרשמים בחשבון בדיקה במייל אמיתי, ובודקים: מייל אימות מגיע ← הקישור עובד ← "שכחתי סיסמה" מגיע ← איפוס עובד. אם אין מייל: `fly logs -a dailyplanner` ויראו שורה "שליחת מייל ... נכשלה" עם הסיבה.

אפשר להשתמש גם בספק אחר שתומך ב-SMTP: `SMTP_URL=smtps://משתמש:סיסמה@שרת:465` (או `smtp://...:587` עם STARTTLS). אם בסיסמה יש תווים מיוחדים, מקודדים אותם (למשל `@` ← `%40`). השרת מסרב לשלוח סיסמה בגלוי לשרת מרוחק שלא מציע STARTTLS.

## משתנים
| משתנה | חובה? | משמעות |
|---|---|---|
| `SMTP_URL` | להפעלת מיילים | כתובת השרת והאישורים |
| `MAIL_FROM` | להפעלת מיילים | השולח, למשל `היום שלי <noreply@example.com>` |
| `BASE_URL` | מומלץ | הכתובת הציבורית לקישורים במיילים. אם חסר, נגזרת מהבקשה |
| `OPERATOR_NAME`, `CONTACT_EMAIL` | מומלץ | מופיעים במדיניות הפרטיות ובתנאי השימוש |
| `MAIL_PROVIDER_NAME` | אופציונלי | שם ספק המיילים, מופיע במדיניות הפרטיות |
| `SMTP_INSECURE_TLS=1` | רק לבדיקות | מתעלם מתעודה לא תקפה. **לא להפעיל בפרודקשן** |
