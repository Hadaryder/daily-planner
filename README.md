# היום שלי — גרסה עצמאית (בלי claude.ai)

מתכנן יומי צבעוני בעברית: משימות, לו״ז, אוכל וצעדים, ציון יומי, לוח שנה, חברים וגלויות.
חשבונות משלו (מייל וסיסמה), שמירת נתונים בשרת, וחישוב קלוריות AI אופציונלי.
שרת אחד ב-Node 22 בלי תלויות npm. מסד הנתונים הוא SQLite מובנה.

האתר החי: https://dailyplanner.fly.dev

## שמירת מידע — בקצרה
- **כל הנתונים** יושבים בקובץ אחד, `/data/planner.db`, על **נפח אחסון קבוע** של Fly (`dp_data`). פריסת קוד מחליפה רק את הקוד ולא נוגעת בנפח.
- **גיבוי אוטומטי** נשמר ב-`/data/backups` לפני כל עלייה של גרסה (`boot-*`) ופעם ביממה (`daily-*`). נשמרים 8 אחרונים מכל סוג.
- **שומר בצינור הפריסה** חוסם פריסה אם משהו משנה את שם האפליקציה או את הנפח (הדרך היחידה "להתחיל מאפס" בטעות).
- **שחזור** בטוח מגיבוי: משתנה סביבה `RESTORE_FROM` (פרטים ב-[docs/DATA-SAFETY.md](docs/DATA-SAFETY.md)). המצב הנוכחי נשמר לפני שמחליפים.
- **כלל קוד:** שינויי מסד נתונים רק מוסיפים (טבלה או עמודה חדשה), לעולם לא מוחקים או משנים משמעות.

## פריסה — בקצרה
כל מיזוג ל-`main` מריץ בדיקות, ואם עברו, מעלה לאוויר אוטומטית (GitHub Actions ← Fly.io).
שינוי רגיל: ענף חדש ← pull request ← הבדיקות רצות ← מיזוג ← האתר מתעדכן. הפרטים ב-[docs/CI-CD.md](docs/CI-CD.md).

## הרצה מקומית
```bash
node --no-warnings server.mjs        # נדרש Node 22.13 ומעלה
# http://localhost:3000
node --no-warnings tests/api.test.mjs  # בדיקות (השרת, הפרטיות, גיבוי ושחזור)
```

## משתני סביבה
ראו `.env.example` (אם קיים). החשובים:
- `DATA_DIR` תיקייה קבועה (volume) שבה נשמר `planner.db` ותיקיית `backups/`
- `COOKIE_SECURE=1` כשהאתר מאחורי HTTPS (חובה בפרודקשן)
- `TRUST_PROXY=1` רק מאחורי פרוקסי (Fly, Caddy): נותן זיהוי נכון של כתובת הלקוח להגבלת קצב
- `ANTHROPIC_API_KEY` אופציונלי. בלעדיו כפתור "חשבו עם AI" מציג "לא זמין". המכסה היומית למשתמש: `AI_DAILY_LIMIT`
- `ALLOW_SIGNUP=0` סוגר הרשמה לחשבונות חדשים
- `RESTORE_FROM` שחזור חד-פעמי מגיבוי (ראו DATA-SAFETY)

## אבטחה ופרטיות (מה כבר קיים)
סיסמאות ב-scrypt עם salt. עוגיית סשן HttpOnly + SameSite=Lax. בדיקת Origin בכל פעולת שינוי. CSP וכותרות אבטחה.
הגבלת קצב על כניסה, הרשמה, הוספת חברים וגלויות. ציונים מוצגים רק לחברים שאישרו הדדית; משימות, לו״ז, אוכל ויומן לא נחשפים לאף אחד.
כל משתמש יכול לייצא את הנתונים שלו ולמחוק את החשבון (בהגדרות).

## מבנה
